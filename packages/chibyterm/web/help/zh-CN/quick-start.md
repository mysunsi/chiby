# 快速开始

欢迎使用 **ChibyTerm（赤壁终端）**——面向运维的 AI Web 终端。

## 第一次打开

1. 使用默认账号登录（若启用了登录）：`admin` / `admin`  
2. 点击顶栏 **「+」**，选择已配置的主机，打开远程终端。  
3. 在左侧终端里直接敲 Shell 命令，或在右侧用自然语言提问。  
4. 需要向多台已打开主机做同一件事时：右侧选 **🌐 Fleet**（详见帮助 **「Fleet（集群群发）」**）。  
5. 需要 LLM 时，打开右上角菜单 → **模型设置**，配置 API。

## 界面分区

| 区域 | 作用 |
|------|------|
| 顶栏 | 品牌、主题切换、用户菜单（帮助 / 模型 / 关于 / 改密） |
| 会话 Tab | 每个打开的主机一个标签；可切换、关闭 |
| 左侧终端 | SSH / WinRM 交互式 Shell（xterm） |
| 右侧面板 | 自然语言、计划确认、说明与闭环进度（可收起） |
| 底栏 | 终端尺寸、Shell 类型、字号等 |

## 推荐路径

请使用左侧目录依次阅读：

1. **主机与终端** — 添加主机并打开会话  
2. **模型设置** — 配置 LLM 后体验自然语言  
3. **确认卡与安全** — 了解高危命令确认机制  
4. **常见问题** — 排障速查  

> 更完整的发布与干净环境试用，见仓库文档 `docs/chibyterm-package-release-handbook.md`。
