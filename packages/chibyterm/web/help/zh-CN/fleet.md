# Fleet（集群群发）

Fleet 用**同一条自然语言意图**，对**所有已打开终端**按操作系统分别生成命令并下发，再按需生成**总体分析报告**。适合 Windows / Linux 混部巡检。

## 操作路径（闭环）

1. （推荐）在 **Fleet 目标范围** 勾选主机或点静态组芯片；或勾选「仅已打开 Tab」  
2. 需要多机排查时：点摘要旁 **「排查」** → 写入当前范围并打开掌上 IM（顶栏显示「组名 · N 台」）；排查过程有 **进度面板**（阶段/主机/工具），诊断结束后可 **存入知识库**；审计见 `/demo/mobile-audit` 平台审计 / `trace_id`  

3. 输入自然语言 → 确认预览并下发  
   - **范围选机**：按主机 **oneshot** 直连执行，**不会**为未打开主机批量创建终端 Tab（只需保留至少一个 Tab 看预览/进度）  
   - **仅已打开 Tab**：仍走各终端会话下发（旧路径）  
4. **执行面板**（常显，不折叠）：
   - 进度文案 `{已完成}/{总数}` + **进度条**
   - **逐台主机行**：🖥 主机名 · 命令 · ✔成功/✖失败 · ▼（点行展开明细）
   - **失败主机**自动高亮并默认展开明细  
5. 全部完成后显示**执行摘要**，以及：  
   - **口吻下拉**（通用/风险/容量/策略）+ **生成报告**（按需，不自动出报告）  
   - **定时生成**：带入本次主机/意图，保存为服务端定时任务  
6. 报告区完整展示（含行动建议等章节），可 **导出 Markdown** / **导出 PDF**，并显示 **关联知识**；可 **存为知识模板**（`source=fleet_report`，带 `trace_id`）  
7. 定时任务若**连续 3 次异常**，Fleet 模式会提示是否沉淀为知识模板

## 主机分组

- 顶栏 **「+」→ 主机分组**：创建静态组；成员列表支持搜索与分页勾选  
- Fleet 范围选机：搜索 / 标签·状态筛选 / 分页（与主机列表同源 `/api/hosts`）；组芯片仍快捷并入 `host_ids`
- 主机分组弹窗：搜索 + 分页勾选成员（跨页勾选草稿保留）；跑批为 **oneshot**（不开 Tab）
- 「仅已打开 Tab」保留会话下发
- 主机表单可编辑 **标签 / 属性 / 状态**（测连成功会标为在线）
- 定时任务用保存的 `host_ids`，同样不依赖打开 Tab

## 入口

- 右侧交互模式 **🌐 Fleet**
- 默认口吻：右上角菜单 → **群发设置**（生成报告时可临时覆盖）

## 与 Agent / Shell

| 模式 | 范围 | 说明 |
|------|------|------|
| Agent / Shell | 当前会话 | 单机 |
| Fleet | 范围选机 oneshot / 或已打开会话 | 按 OS 异构命令 + 摘要/报告/定时 |

## 定时任务

- 配置：每天或每周 + 时刻；失败策略；通知勾选（飞书/邮件/企微**即将支持**，先占位）  
- 到期后服务端 **oneshot** 执行（不依赖打开 Tab），再按策略生成报告  
- 结果写入任务的 `last_status` / `last_report_md`（服务端日志可查）

## 注意

- **范围选机**：oneshot，不强制开 Tab；至少保留一个终端用于看 Fleet 进度  
- **仅已打开 Tab**：即时群发走各会话 PTY  
- 定时任务用保存的 `host_ids`（oneshot）  
- **同主机多 Tab 默认去重**（仅「已打开 Tab」模式）：按 `host_id` 合并，优先保留当前聚焦终端；预览会标明「合并重复 N 个」，可勾选「保留全部终端」关闭去重  
- 命令经策略网关；优先只读巡检  
- 下发前务必核对 OS 分段命令预览
