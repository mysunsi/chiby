# 登录与账号

## 默认账号

启用 UI 登录时（默认开启）：

- 用户名：`admin`  
- 密码：`admin`  

首次登录后请尽快 **修改密码**（右上角菜单 → 修改密码）。

## 修改密码

1. 使用当前用户名与当前密码验证。  
2. 新密码至少 4 位。  
3. 保存成功后需用**新密码重新登录**（旧会话会失效）。

凭证哈希保存在工作目录 `data/ui_auth.json`，请勿把该文件提交到公开仓库。

## 关闭登录（可选）

若仅内网调试、不需要登录门禁，可在启动前设置：

```text
OPS_UI_AUTH=0
```

关闭后接口不再要求 Cookie；生产环境建议保持开启。
