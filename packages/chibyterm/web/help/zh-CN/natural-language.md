# 自然语言运维

配置好 LLM 后，可在右侧对话区用中文描述意图，由模型生成 Shell 并（在确认后）执行。

## 怎么用

1. 先打开至少一个主机终端会话。  
2. 展开右侧 AI 面板（贴边机器人图标可打开）。  
3. 输入自然语言，例如：  
   - 「查看磁盘使用情况」  
   - 「检查 nginx 是否在运行」  
   - 「看最近 10 条错误日志」  
4. 按界面提示执行、编辑或取消建议命令。

## 模式说明（常见）

| 模式 | 含义 |
|------|------|
| Agent | 当前会话：计划预览与确认 |
| Shell | 当前会话：译为命令后可自动下发 |
| Fleet | **全部已打开会话**：按 OS 分段命令后群发并汇总报告（详见 **「Fleet（集群群发）」**） |

具体选项以右侧下拉为准；未配置 LLM 时仍可当普通 Web 终端使用。

## 与闭环的关系

部分失败步骤可触发**受控闭环**（重试 / 摘要 / 网关策略）。闭环过程多在右侧展示，默认不污染左侧交互式终端输出。详见「确认卡与安全」。
