# 确认卡与安全

ChibyTerm 强调：**变更前确认、事后可审计**。

## 确认卡

当模型或系统判定命令为**高危**（如大规模删除、关机、账户变更等）时，会弹出确认卡：

- 展示将要执行的命令与风险提示  
- 需要你明确 **允许** 后才会执行  
- 可拒绝 / 取消，避免误操作  

## 策略与网关

服务端执行网关可对命令做策略拦截、变更窗口、冻结队列等（视配置启用）。环境变量多以 `OPS_POLICY_*`、`OPS_CLOSURE_*` 等形式出现，详见仓库文档与运维手册。

## 建议实践

1. 生产主机先用只读类命令验证连通与权限。  
2. 高危操作前在确认卡中逐字核对路径与主机。  
3. **Fleet 集群群发**会对所有已打开会话下发（按 OS 异构命令），请格外谨慎；优先只读巡检，并依赖策略网关拦截。详见帮助 **「Fleet（集群群发）」**。  
4. 不要在公开仓库提交 `hosts.json` 明文密码。  
5. 定期修改 UI 登录密码（右上角菜单 → 修改密码）。
