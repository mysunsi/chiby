# 確認卡與安全

ChibyTerm 強調：**變更前確認、事後可稽核**。

## 確認卡

當命令被判定為**高危**（大量刪除、關機、帳號變更等）時，會彈出確認卡：

- 展示將要執行的命令與風險提示  
- 需明確 **允許** 後才會執行  
- 可拒絕 / 取消，避免誤操作  

## 策略與閘道

服務端執行閘道可對命令做策略攔截、變更視窗、凍結佇列等（視設定啟用）。環境變數多以 `OPS_POLICY_*`、`OPS_CLOSURE_*` 等形式出現，詳見倉庫文件。

## 建議實務

1. 生產主機先用唯讀類命令驗證連通與權限。  
2. 高危操作前在確認卡中逐字核對路徑與主機。  
3. **Fleet 集群群發**會對所有已開啟工作階段下發（按 OS 異構命令），請格外謹慎；優先唯讀巡檢，並依賴策略閘道攔截。詳見說明 **「Fleet（集群群發）」**。    
4. 不要在公開倉庫提交 `hosts.json` 明文密碼。  
5. 定期修改 UI 登入密碼（右上角選單 → 修改密碼）。
