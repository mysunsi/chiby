# Fleet（集群群發）

Fleet 用自然語言意圖對已開啟終端按 OS 分命令下發；執行完成後先看摘要，再**按需產生報告**或**定時產生**。

## 閉環

1. 選 **🌐 Fleet** → 在目標範圍勾選主機/靜態組（或「僅已開啟 Tab」）→ 可點 **「排查」** 進入掌上 IM 多機診斷 → 確認預覽並下發  

2. 執行面板常顯：進度 `{完成}/{總數}` + 進度條；逐台主機行（✅/❌，可展開明細）；失敗自動高亮展開  
3. 完成後：口吻下拉 + **產生報告** / **定時產生**  
4. 報告完整展示（含行動建議），可匯出 Markdown 或 PDF（列印另存）

定時任務到期後由服務端 oneshot 執行（不依賴開啟 Tab）；通知管道即將支援。

## 去重與分組

同主機多 Tab **預設按 host_id 去重**；頂欄「主機分組」可維護靜態組供 Fleet 範圍選機。
