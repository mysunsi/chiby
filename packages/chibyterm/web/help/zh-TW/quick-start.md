# 快速開始

歡迎使用 **ChibyTerm（赤壁終端）**。

## 第一次開啟

1. 以 `admin` / `admin` 登入（若啟用登入）。
2. 點頂欄 **「+」** 選擇主機，開啟遠端終端。
3. 左側敲 Shell；右側可用自然語言。
4. 需對多台已開啟主機做同一件事時：右側選 **🌐 Fleet**（詳見說明 **「Fleet（集群群發）」**）。  
5. 右上角選單 → **模型設定** 配置 LLM。

## 介面分區

| 區域 | 作用 |
|------|------|
| 頂欄 | 品牌、主題、語言、使用者選單 |
| 分頁 | 每個已開啟主機一個標籤 |
| 左側終端 | SSH / WinRM 互動 Shell |
| 右側面板 | 自然語言、計畫與確認 |

請使用左側目錄繼續閱讀「主機與終端」「模型設定」「確認卡與安全」。
