# 主機與終端

## 新增主機

1. 點頂欄 **「+」** → **新增主機**。  
2. 填寫名稱、位址、連接埠、使用者名稱、密碼（或 SSH 私鑰路徑）。  
3. 選擇連線類型：  
   - **SSH**：Linux / 多數 Unix  
   - **WinRM**：Windows（可調傳輸、SSL、Shell 模式）  
4. 可用 **測試連線** 驗證後再儲存。

主機清單位於服務端工作目錄下的 `data/hosts.json`（**勿把真實密碼提交到公開倉庫**）。

## 開啟工作階段

- 在「+」選單中點某台主機 → 新建終端 Tab。  
- 每個 Tab 對應獨立工作階段與 xterm。  
- 關閉 Tab 會結束對應遠端工作階段（請注意未儲存操作）。

## 集群群發

跨機、按 OS 異構命令的群發與總體報告，見說明目錄 **「Fleet（集群群發）」**。

## 終端操作提示

- 與常見 SSH 用戶端類似：鍵盤輸入直接送給遠端。  
- 底欄可調整字級；目標系統選項會影響部分自然語言適配。

## 資料目錄

程式在**啟動時的工作目錄**下讀取 `data/`：

- 本倉開發：通常在 `Assistant/` 下啟動。  
- `pip install` 乾淨試用：請在自建工作目錄準備 `data/` 後再啟動。
