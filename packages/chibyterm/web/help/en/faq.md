# FAQ

**Hosts fail to load?** Start the backend over http and sign in first.

**NL does nothing?** Check Model settings and network to the LLM API.

**Where is Fleet broadcast?** Help nav **Fleet (cluster broadcast)**. Mode **🌐 Fleet**; default report tone under top-right menu **Broadcast settings**. Open tabs (or scope) only; commands are generated per OS.

**Python version?** Requires Python ≥ 3.10. Use `chibyterm.main:app` after pip install.
