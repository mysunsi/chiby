# Quick start

Welcome to **ChibyTerm** — an AI-driven Web ops terminal.

## First open

1. Sign in with `admin` / `admin` (if UI auth is enabled).
2. Click **+** in the tab bar, pick a host, open a remote terminal.
3. Type shell commands on the left, or ask in natural language on the right.
4. For the same intent across open hosts: set **🌐 Fleet** (see **Fleet** in Help).  
5. Configure LLM via the top-right menu → **Model settings**.

## Layout

| Area | Role |
|------|------|
| Header | Brand, theme, language, user menu |
| Tabs | One tab per open host session |
| Left terminal | Interactive SSH / WinRM (xterm) |
| Right panel | NL chat, plans, confirmations (collapsible) |

Use the left help topics for hosts, models, and safety.
