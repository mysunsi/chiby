终端管理软件界面综合需求
（含本地/云端大模型配置）  
一、头部栏布局与交互  
1. 左侧：软件名称，采用 Segoe UI Variable 字体，字号 14px，距左侧边框 16px 垂直居中。  
2. 中间：多页签区域，支持拖拽排序（参考 SortableJS 实现，拖拽时页签显示 80% 透明度+2px 阴影，排序结果本地持久化）；页签默认不显示关闭“×”图标，鼠标 hover 时显示在右侧；页签最左侧嵌入 8×8px 圆形状态指示灯，颜色规则：未连接-浅灰（#CCCCCC）、连接成功-深绿（#008000）、异常-亮红（#FF0000）。  
3. 右侧：  
   - 第一个按钮：“+”图标（16×16px），点击弹出下拉菜单（最大高度 300px，超出滚动），顶部固定“新增主机”选项（加粗），下方列出已保存主机（格式：“别名（IP:端口）- 最后连接时间”），无主机时显示“暂无主机，点击上方‘新增主机’添加”（灰色斜体）。  
   - 第二个按钮：齿轮图标（16×16px），点击打开“大模型设置”面板（模态窗口，宽度 500px）。  
二、核心功能细节  
1. 新增主机流程：  
   - 点击“新增主机”后弹出表单，包含字段：主机别名（必填）、IP 地址（必填，格式校验）、端口（必填，默认 22）、用户名（必填）、认证方式（单选：密码/密钥文件路径）。  
   - 表单底部有“保存”和“取消”按钮，保存后主机信息存入本地配置文件（JSON 格式），并刷新主机列表。  
2. 大模型设置面板（分类型配置）：  
   - 顶部类型切换：单选组“模型类型”，含“云端 API”和“本地部署”两个选项，默认“云端 API”。  
   - 云端 API 配置（选中时显示）：  
     - 模型选择：下拉菜单，选项包括“OpenAI”“DeepSeek”“智谱 AI”“自定义”，选“自定义”时显示“供应商名称”输入框。  
     - API Key：密码类型输入框（显示“••••••••”），必填。  
     - Base URL：文本输入框，选非自定义模型时自动填充默认值（如 OpenAI 填“https://api.openai.com/v1”），支持手动修改。  
     - 允许模型列表：文本输入框，提示“用逗号分隔，如：gpt-4o-mini,deepseek-chat”，必填。  
   - 本地部署配置（选中时显示，默认适配 Ollama）：  
     - 部署工具：下拉菜单，默认“Ollama”（暂不支持其他工具）。  
     - 模型名称：文本输入框，提示“如：llama3:8b、qwen:7b”，必填（需匹配 Ollama 本地模型标识）。  
     - 本地服务地址：文本输入框，默认“http://localhost:11434”（Ollama 默认 API 端口），支持修改。  
     - 高级配置（可折叠区域）：  
       - 上下文窗口大小：数字输入框，默认 4096，最小值 1024。  
       - 温度参数：滑块（0-1），默认 0.7。  
       - GPU 使用数量：下拉菜单，选项“自动”“0（仅 CPU）”“1”“2”（根据本地 GPU 数量动态生成）。  
   - 通用操作：面板底部有“测试连接”（点击后验证配置有效性，显示“连接成功”/“失败原因”提示）和“保存配置”按钮，配置信息存入本地加密文件。  
三、视觉与交互规范  
- 主题适配：支持浅色/深色模式，标题栏背景默认使用 Mica 材质（Windows），非活动窗口时所有元素透明度降至 70%。  
- 响应式：窗口宽度小于 800px 时，主机列表下拉菜单最大宽度限制为窗口宽度的 80%，避免溢出。  
- 错误提示：状态指示灯异常时，鼠标 hover 显示 tooltip（如“连接超时”“认证失败”），基于终端连接错误码映射。  
（注：技术实现可参考 xterm.js 渲染终端、WebSocket 实时通信、Ollama REST API 调用本地模型。）
