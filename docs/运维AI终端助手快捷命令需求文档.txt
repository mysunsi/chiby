运维AI终端助手快捷命令需求文档  
一、核心设计原则  
1. 运维场景优先：聚焦服务器管理、故障排查、资源监控等高频运维动作。  
2. 轻量高效：通过斜杠命令快速触发，减少鼠标操作，支持参数补全。  
3. 安全可控：高危操作需二次确认，支持权限分级配置。  
二、快捷命令清单  
| 命令         | 功能描述                                                                 | 参数示例                          | 适用场景                          |  
|------------------|-----------------------------------------------------------------------------|---------------------------------------|---------------------------------------|  
| `/help`          | 显示所有快捷命令及用法，支持筛选分类。                                     | `/help 监控`                          | 新手入门、命令记忆模糊时              |  
| `/clear`         | 清空当前会话上下文，保留终端历史命令。                                     | 无                                    | 对话逻辑混乱、切换任务主题时          |  
| `/new`           | 新建独立会话，完全隔离上下文，生成会话ID便于回溯。                        | 无                                    | 多任务并行处理、敏感操作隔离时        |  
| `/setup`         | 调出配置面板，支持模型切换、高危命令拦截等级、API Key绑定。               | 无                                    | 首次使用配置、环境参数调整时          |  
| `/model`         | 快速切换AI模型，轻量模型节省资源，高性能模型处理复杂任务。                | `/model gpt-4o` / `/model gpt-3.5-turbo` | 简单命令生成用轻量模型，脚本编写用高性能模型 |  
| `/history`       | 查看当前会话命令执行历史，支持按“成功/失败”筛选，点击可重新执行。         | `/history 失败`                      | 排查命令执行错误、复用历史有效命令时  |  
| `/explain_last`  | 自动解释上一条执行命令的参数含义、作用及风险提示。                         | 无                                    | 执行陌生命令后理解细节、新手学习时    |  
| `/monitor`       | 实时监控系统核心指标，支持自定义监控项。 | `/monitor cpu,mem,disk`              | 服务器响应变慢、日常巡检时            |  
| `/log`           | 快速检索指定日志文件，支持关键词筛选和时间范围。                           | `/log /var/log/nginx/access.log error 1h` | 服务报错时定位日志关键信息            |  
| `/exec`          | 直接执行生成的Shell命令，高危命令自动标红并二次确认。                      | `/exec "rm -rf /tmp/old_logs"`      | 确认命令安全后快速执行，减少复制粘贴步骤 |  
三、交互细节  
1. 命令触发：输入 `/` 后自动弹出命令补全菜单，支持上下键选择。  
2. 参数提示：需参数的命令会显示灰色提示，如 `/model <模型名称>`。  
3. 高危拦截：执行 `kill`、`rm -rf` 等高危命令时，终端显示红色警告框，需手动输入“确认”方可执行。  
4. 快捷键联动：支持 `Ctrl+Shift+I` 快速进入AI模式，`Shift+Enter` 强制触发自然语言交互。  
四、扩展建议  
- 容器管理：新增 `/docker ps`、`/docker logs <容器ID>` 等命令，适配容器化运维场景。  
- 日志分析：集成 `/log_ai <关键词>`，让AI自动总结日志异常模式。  
- 自定义命令：支持用户通过 `/add_cmd` 上传bash脚本，生成个性化斜杠命令。
