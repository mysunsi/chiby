## ② 解决什么问题（3 条短句）

1. 企业要的是 **能进流程的 AI**，不是只能聊天的模型。  
2. 变更怕失控 → 需要 **人机确认 + 全程留痕**。  
3. 业务数据在 Excel/办公系统里 → 需要 **长在自有数据上**，数据可不出域。

## ④ 差异化（壁垒 · 1 段 + 3 标签）

**核心句：**  
壁垒不是「又一个 Agent 框架」，而是 **赤壁长在小思十年业务骨架上**（表单·审批·文件数据·权限），别人难以一夜重建。

| 标签 | 短句 |
|------|------|
| 规划脑 + 执行宿主 | 模型负责想；赤壁负责做与护栏 |
| 数据可私有化 | 企业版目标：业务与审计留在客户环境 |
| 工具化架构 | 能力可插拔；业务将以同一工具契约接入 |

灰色小字：**小思深度咬合、统一登录 = 路线图（设计已定）** —— 避免当成现货。

## 一页成品文案（可直接贴进排版 · 精简版）

**赤壁（Chiby）— 企业级 AI 成长助手**  
自然语言做运维与知识工作；变更先确认、事后可审计；能力长在企业自有业务数据上。

**痛点** 要的是能进流程的 AI · 怕失控要护栏 · 数据要留在自己环境。  

**现已可演示** 掌上三模式 Agent · 确认卡与审计 · 知识/文档双轨 · 工具插件与多机任务。  

**为何不同** 规划脑负责「想」，赤壁负责「做与护栏」；更深壁垒是接入小思真实业务对象与权限（深度咬合推进中）。  

**商业** 社区免费 · 专业 5–10 万/年 · 企业 15–30 万/年 · 行业方案 30–50 万/项目。  

**下一步** 演示就绪 → 登录与小思事务接入 → 影子验证与规模化业务工具。
