# 安全政策

## 报告漏洞

请**不要**通过公开 Issue 报告安全漏洞。改为私邮 **security@chiby.ai**（或 `security@{{DOMAIN}}`），或在 GitHub Security Advisories 中提交私密报告。

## 范围

- **本仓库（开源 ChibyTerm / chibycore）**：执行护栏、确认卡、审计、SSH/WinRM、闭环治理、KB/Doc、Fleet 基础能力。
- **不在范围**：智能型/全能型运维中枢、掌上机房后端、Hermes/Chiby 桥、许可与专利增值。请向商业支持渠道报告。

## TSM-A 说明

开源版实现 TSM-A 的 L1（确认卡 / 风险判定）与基础审计；链式哈希 / 策略令牌等为 Pro 增值。我们**不**声称「Prompt Injection 已根治」。

## 响应时限

- 确认收到：5 个工作日内
- 初评与修复排期：视严重级别约 30 天内沟通

## 致谢

对负责任披露的研究者，经确认后将在 CHANGELOG / 安全公告中致谢（如同意）。
